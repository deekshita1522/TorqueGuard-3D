TORQUEGUARD 3D: Embedded Systems Technical Architecture

Project Viva Reference: Mathematical Models, RTOS Tasks & Anti-Inrush Debounce Firmware

Target MCU: STM32F401 / ESP32 Industrial Node. Below is the production-grade embedded C state machine implementation executing inside a 100Hz FreeRTOS task with hardware timer debouncing:

/* ==================================================================== * TORQUEGUARD Embedded Firmware Core - Stall Detection & Safe Recovery * Target: STM32F4 / ARM Cortex-M4 @ 84MHz (FreeRTOS) * ==================================================================== */ #include "stm32f4xx_hal.h" #include "FreeRTOS.h" #include "task.h" typedef enum { STATE_NORMAL, STATE_SUSPECT, STATE_STALL_CONFIRMED, STATE_RECOVERY, STATE_LOCKOUT } TorqueGuardState_t; static TorqueGuardState_t g_systemState = STATE_NORMAL; static uint32_t g_stallPersistenceCount = 0; static uint8_t g_recoveryAttempts = 0; #define STALL_CURRENT_THRESHOLD_MA 6000 // 6.0A in mA #define STALL_RPM_THRESHOLD 5 // < 5 RPM #define STALL_POS_ERROR_THRESHOLD 25 // > 25% Error #define DEBOUNCE_TICKS_3SEC 300 // 300 ticks @ 10ms task = 3.0 seconds void vTaskStallDetection(void *pvParameters) { TickType_t xLastWakeTime = xTaskGetTickCount(); for (;;) { // 1. Read Current from ADC via DMA (ACS712 Hall Sensor) uint32_t current_mA = ADC_GetCurrent_mA(); // 2. Read Optical Encoder Speed from TIM2 32-bit QEI peripheral uint32_t currentTicks = __HAL_TIM_GET_COUNTER(&htim2); int32_t actualRPM = Calculate_Encoder_RPM(currentTicks); int32_t targetRPM = Get_Commanded_RPM(); // 3. Compute Position Error Percentage int32_t posError = (targetRPM > 0) ? ((targetRPM - actualRPM) * 100) / targetRPM : 0; // 4. Evaluate 5-Criteria Multi-Factor Stall Gate bool c1_currentHigh = (current_mA > STALL_CURRENT_THRESHOLD_MA); bool c2_rpmLow = (actualRPM < STALL_RPM_THRESHOLD); bool c3_encoderStatic = (actualRPM == 0); bool c4_posErrorHigh = (posError > STALL_POS_ERROR_THRESHOLD); bool instantaneousStall = c1_currentHigh && c2_rpmLow && c3_encoderStatic && c4_posErrorHigh; // 5. Anti-Inrush Debounce Filter (Criterion 5: 3.0s Persistence) if (instantaneousStall) { g_stallPersistenceCount++; if (g_systemState == STATE_NORMAL) { g_systemState = STATE_SUSPECT; HAL_GPIO_WritePin(WARN_LED_PORT, WARN_LED_PIN, GPIO_PIN_SET); } if (g_stallPersistenceCount >= DEBOUNCE_TICKS_3SEC) { // CONFIRMED STALL - Prevent Inrush False Alarm! g_systemState = STATE_STALL_CONFIRMED; Execute_Protective_Recovery(); } } else { // Transient cleared (e.g. startup inrush completed within 300ms) if (g_stallPersistenceCount > 0) g_stallPersistenceCount--; if (g_systemState == STATE_SUSPECT && g_stallPersistenceCount == 0) { g_systemState = STATE_NORMAL; HAL_GPIO_WritePin(WARN_LED_PORT, WARN_LED_PIN, GPIO_PIN_RESET); } } vTaskDelayUntil(&xLastWakeTime, pdMS_TO_TICKS(10)); // 100Hz loop } }

1. DC Motor Dynamic Equations (Why Inrush Occurs)

V(t) = I(t) · R_a + L_a · \frac{dI}{dt} + K_e · ω(t)

At startup or locked-rotor stall, rotor angular velocity ω = 0. Therefore, Back-EMF (K_e · ω) is exactly 0V! The full bus voltage is applied across the armature resistance (R_a = 1.2Ω), causing a huge current spike (I = V / R_a ≈ 7.5A). Naive current sensors immediately trip, creating false alarms. TorqueGuard avoids this by enforcing the 3.0s persistence duration!

2. Lumped Parameter Thermal Dynamics (Joule Heating ODE)

\frac{dT_{motor}}{dt} = \frac{I(t)^2 · R_a}{C_{th}} - \frac{T_{motor} - T_{ambient}}{R_{th} · C_{th}}

Joule dissipation scales quadratically with current (I²). Under 2.4A normal load, heat generation is 6.9 Watts. Under 7.4A locked stall, heat generation surges to 65.7 Watts (a 950% increase!). Furthermore, convective air cooling halts because the internal fan stops spinning, leading to exponential temperature runaway.

3. Quadrature Optical Encoder Position Error

E_{pos} = \frac{|\omega_{target} - \omega_{actual}|}{\omega_{target}} \times 100\%

Enables differentiation between heavy payload drag (ω ≈ 70 RPM, Error ≈ 15%) versus total mechanical seizure (ω = 0 RPM, Error = 100%).

Embedded Microcontroller Peripheral Mapping

  • MCU Core: ARM Cortex-M4 32-bit RISC with Hardware FPU (Floating Point Unit) @ 84MHz.
  • TIM1 Advanced Timer: 20kHz Complementary PWM with Dead-Time Insertion driving Dual H-Bridge MOSFET gate drivers (VNH5019 / L6203).
  • TIM2 General Purpose Timer: Configured in 32-bit Quadrature Encoder Interface (QEI) mode decoding Channel A & B pulses from Omron 1024 PPR optical encoder without CPU overhead.
  • ADC1 + DMA: Continuous 12-bit circular DMA sampling of ACS712 Hall-Effect current sensor with 16x hardware oversampling filter.
  • SPI1 Peripheral: Communicates with MAX31865 RTD amplifier digitizing PT100 platinum temperature probe to 0.03°C resolution.
  • Safety Relay Contactor: Hardware-latched independent safety coil in series with main DC bus, triggered immediately on LOCKOUT or E-STOP.
